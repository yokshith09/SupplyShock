# SupplyShock Action Agent

Executes an approved supply-disruption response plan: sends RFQs to alternate suppliers, sends expedite requests to current suppliers, generates draft purchase-order PDFs and drafts customer delay or assurance notices. It never acts without explicit user approval, and in demo mode all email goes to a controlled inbox.

**Keywords:** RFQ, purchase order, expedite, procurement, supplier, supply chain, manufacturing, customer notice

This agent is used through the **SupplyShock Orchestrator**. Start there with:
- Cyclone warning on the Tamil Nadu coast, are we exposed?
